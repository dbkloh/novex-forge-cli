# novex-forge CLI

**Binaries only — source code is private.**

## Install

```bash
curl -fsSL https://novex-auth-server.vercel.app/install.sh | bash
```

## Manual download

Download the latest binary from [Releases](https://github.com/dbkloh/novex-forge-cli/releases/latest).

| Platform | File |
|----------|------|
| macOS arm64 | `novex-forge-macos-arm64` |
| macOS x64 | `novex-forge-macos-x64` |
| Linux x64 | `novex-forge-linux-x64` |
| Windows x64 | `novex-forge-windows-x64.exe` |
